## 本部分要解决的问题

算法正确只是系统闭环的一部分。平台需要把业务数据送入算法，把推荐结果保存和审核，把命令送到设备，并把执行状态反馈到操作界面。

## 阅读路径

第 19 章说明 Java 服务组织与 Python 算法边界；第 20 章处理事件时间和实时数据；第 21 章建立下发状态机；第 22 章把前端操作与运行日志连接起来。

## 状态链

```text
输入数据 -> 推荐方案 -> 人工审核 -> 调度
         -> 命令下发 -> 设备接受 -> 运行确认
```

每一段都需要独立标识、版本、状态和失败原因。业务层不能把自己的成功返回误认为设备已经执行。
