# 附录 A 全书符号表

如表 A-1 所示。
表 A-1 全书符号表
| 符号 | 含义 | 单位 |
|---|---|---|
| `q` | 到达需求 | veh/h |
| `S` | 饱和流率 | veh/h |
| `y` | 流量比 `q/S` | 无量纲 |
| `Y` | 关键阶段流量比之和 | 无量纲 |
| `c` | 平均通行能力 | veh/h |
| `x` | 饱和度 `q/c` | 无量纲 |
| `C` | 信号周期 | s |
| `g` | 纯绿或阶段绿信时间，使用时必须明确 | s |
| `f` | 绿闪时间 | s |
| `y_i` | 黄灯时间，正文中避免与流量比同段使用 | s |
| `r` | 全红时间 | s |
| `I` | 清空时间 | s |
| `rho` | 阶段时间比例 | 无量纲 |
| `d` | 路段距离 | m |
| `v` | 协调速度 | m/s 或 km/h |
| `o` | 相位差 | s |

## 单位规则

1. 接口字段名应包含单位，例如 `speed_kmh`。
2. 同一公式内不得混用 veh/h、veh/窗口和 veh/s。
3. 阶段总时长的口径必须在章内说明。
