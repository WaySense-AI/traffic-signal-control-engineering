## 1. 本版特点

- 卷首「六场战役地图」，七个部分各有一篇作者评点，串起「兵器—战场—评点」的叙事线。

- 图表编号与题位全书统一：图题在图下、表题在表上，20 张图与 114 张表均有唯一编号和正文引用。
- 421 个代码块按用途分类标注：源码摘录、字段契约、伪代码、运行输出各自使用固定标记，读者不必逐段猜测哪段能跑；可运行的 Python 与 JSON 示例均通过语法检查。
- 版面按 A4 印刷规范校准；PDF 带标签（Tagged），可被读屏软件朗读。
