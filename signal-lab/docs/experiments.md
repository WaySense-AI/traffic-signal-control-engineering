# 实验地图

八个实验按“时间—需求—单点—协调—执行”的顺序组织。每个实验都可以单独运行，不需要网络或外部数据。

| 实验 | 主要输入 | 建议修改 | 观察点 | 书稿位置 |
|---|---|---|---|---|
| `end_to_end_demo` | 车道观测、需求、阶段方案 | 改一个流向流量或饱和流率 | 周期、绿灯、命令状态和评价是否仍然闭合 | 第 1.7、19、21、24.9 节 |
| `corridor_case` | S1～S4 路段长度、速度、周期 | 改路段长度或协调速度 | 公共周期、累计行程时间、偏移和带宽 | 第 24.9 节 |
| `experiment_cycle` | 流量比、损失时间、周期界 | 改流量比或周期上下限 | Webster、分段线性和整数分配的结果差异 | 第 10.12、11.14 节 |
| `experiment_quality` | 检测序列、缺失和异常 | 改缺失位置或阈值 | 质量标志、补全值和置信度如何传播 | 第 5.10、6.9 节；附录 E.3 |
| `experiment_coordination` | 两路口绿窗、行程时间 | 改下游距离或绿窗 | 带宽、事件扫描和偏移是否一致 | 第 17.13、18.7 节 |
| `queue_lab` | 到达率、服务率、存储容量 | 改容量或需求 | 本地排队、溢出和守恒关系 | 第 1.7、7.7 节 |
| `timeline_lab` | 周期、阶段、偏移 | 改偏移或查询时刻 | 半开区间、跨界查询和阶段覆盖 | 第 8.8、16.8、18.7 节 |
| `resilience_lab` | 批次命令、设备响应 | 改失败点或重试顺序 | 部分成功、幂等、回滚和批次状态 | 第 21.7、24.9 节 |

## 记录格式

建议每个实验记录五项：

1. 输入与假设；
2. 运行前预测；
3. 实际输出；
4. 被满足或被破坏的不变量；
5. 差异来源：模型、数据还是实现。

实验输出本身不是结论。测试通过也不等于交通性能改善，二者要分开判断。

## 运行

```bash
python3 run_all.py
python3 run_all.py --examples-only
python3 -m examples.end_to_end_demo
```
