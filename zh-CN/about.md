# 内容简介

交通信号控制不仅是配时公式和优化算法，更是一项贯穿交通工程、数据处理、软件系统与设备执行的综合性工程。

本书以中国大陆城市道路交通信号控制工程为背景，从路口建模、交通数据与控制输入出发，系统讲解单点配时、约束优化、自适应控制、区域协调、双向绿波及控制效果评价，并进一步深入 Java 与 Python 服务协作、实时数据链路、方案下发、设备确认与故障回滚等平台工程环节。

全书以可运行的 SignalLab 教学系统把知识讲解和实验串起来，并结合真实生产系统源码，展示交通控制算法从工程建模、计算实现到现场执行的完整过程，分析其中的关键约束、常见缺陷与验证方法。

本书适合交通工程、智能交通、计算机及相关领域的工程技术人员、研究人员和高校师生阅读，也可作为交通信号控制系统开发与实践的参考。
