# 附录 G 使用边界与安全

本书的代码、参数和案例用于解释信号控制的工程原理，不是可以直接投入现场运行的控制器。

## G.1 示例代码不能直接控制真实信号机

书中的 Python 和 Java 片段是教学示例，缺少现场设备所需的联锁、降级、审计和运维约束。不要把示例代码直接接到真实路口；现场部署必须经过设备联调、冲突与最小绿检查、降级与回滚验证，以及运营审批。

## G.2 参数必须按项目核实

书中的周期、绿信比、最小绿、清空时间和饱和流率，来自规范、设备手册、工程经验或合成案例。它们用于说明计算关系，不是全国通用的设计值。实际项目应以现行规范、设备能力和现场标定为准。

## G.3 数据与图表

书中的 S1–S4、流量、排队和评价数据均为合成数据，不对应真实路口或客户项目。图表由作者绘制或由书稿脚本生成；引用外部标准、论文和设备资料时，只保留必要的书目信息，不复制标准全文或受版权保护的图表。

## G.4 部署前的工程检查

真实部署至少需要确认：

- 冲突相位和清空时间经过独立复核；
- 最小绿、最大绿和行人过街满足适用规范；
- 设备协议、版本和时钟经过现场联调；
- 命令失败、设备离线、网络中断和人工接管有降级路径；
- 方案下发、执行确认、观测和回滚都有审计记录；
- 运营单位完成审批和人员培训。

工程判断不能被“算法算出了一个结果”替代。现场安全、可运维性和责任边界，始终高于离线指标。
